PandoraRigs Maker

Turn a Minecraft skin into a rig for the PandoraRigs plugin. Preview it in 3D, then build the resource pack. Everything happens in your browser; nothing is uploaded anywhere.

1. Add a skin

2. Your rigs

None yet. Every rig you add goes into one pack.

    3. Download

    1. Unzip skins.zip into plugins/PandoraRigs/skins/.
    2. In game, run /rig create <id> <id>.png for each rig.
    3. The plugin hosts the pack itself. Or upload rigs-pack.zip somewhere public (a GitHub release works) and set pack.external-url. You can also merge its assets/ into your server pack and set pack.send: false.

    Preview

    Drag to turn it, scroll to zoom. The preview uses the same bones and UVs as the pack.
